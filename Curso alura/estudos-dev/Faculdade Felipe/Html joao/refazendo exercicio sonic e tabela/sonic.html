Exercicio 1: Criando uma tabela de catálagos livres

Objetivo: Criar uma tabela de catálogo de livro com 5 generos e 4 autores diferentes.

  1. Crie um arquivo HTML básico com a estrutura completa (doctype, html, head, body)
  2. Adicione um título "Catálogo de Livros" usando a tag h1
  3. Crie uma tabela usando as tags de tabela
  4. A primeira linha deve conter cabeçalhos com os gêneros literários
  5. A primeira coluna deve conter os nomes dos autores
  6. Preencha a tabela com títulos de livros de sua escolha

Exercício 2: Estilizando o Catálogo

Objetivo: Aplicar cores e bordas à tabela criada no exercício 1.

  1. Use o CSS para colorir:
    • O cabeçalho da tabela com a cor "#DDDDDD"
    • Células de Ficção com a cor "#FFB6C1" (rosa claro)
    • Células de Não-Ficção com a cor "#B0E0E6" (azul claro)
    • Células de Literatura Infantil com a cor "#FAFAD2" (amarelo claro)
  2. Inclua 8px de espaçamento interno para melhorar o espaçament
  3. Crie divs com cantos arredondados (border-radius) para exibir informações sobre cada gênero literário
  4. Deixe a página o mais próximo possível dessa prova e imagem
